# Чат Telegram

Веб-клиент на React для отправки и получения текстовых сообщений в Telegram через [GREEN-API](https://green-api.com/telegram).

Слева список чатов, справа переписка. Отправляются и показываются только текстовые сообщения.

## Запуск

Нужны Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

Сборка статики:

```bash
npm run build
npm run preview
```

## Перед входом

1. Установите Telegram и зарегистрируйте номер.
2. В [личном кабинете GREEN-API](https://console.green-api.com/) создайте инстанс Telegram и авторизуйте его.
3. Для получения ответов оставьте webhook URL пустым и включите уведомления о входящих сообщениях. Иначе метод `receiveNotification` вернёт ошибку.
4. Скопируйте `apiUrl`, `idInstance` и `apiTokenInstance`.

## Как пользоваться

1. На странице входа укажите данные инстанса. Приложение проверит состояние методом `getStateInstance` и пустит дальше, когда инстанс авторизован.
2. Нажмите «Новый чат» и введите номер телефона или `@username`. Контакт проверяется методом `checkAccount`, в переписку попадает `chatId`.
3. Напишите текст и отправьте его. Запрос уходит методом `sendMessage`. Длина текста — до 4096 символов.
4. Ответ из Telegram появится в том же чате. Входящие забираются методом `receiveNotification` и подтверждаются методом `deleteNotification`.

Учётные данные и история чатов хранятся в `localStorage` браузера. Кнопка «Выйти» удаляет только данные входа, переписка этого инстанса остаётся на компьютере.
